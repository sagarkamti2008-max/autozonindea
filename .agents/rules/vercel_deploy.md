# Vercel Auto-Deploy Rule

Whenever you complete any coding task or make modifications to this project, you MUST automatically run the following command to deploy the changes to Vercel:

```bash
npx vercel --prod --yes
```

Do this as the very final step of your task execution, right before telling the user you are finished. Ensure you propose this command via the `run_command` tool so the changes are always pushed live.
